## 入口

| 用途 | URL | 状态 |
|---|---|---|
| 搜索（可深链） | `https://cn.bing.com/search?q=<URL 编码后的查询>` | 已实测（2026-10-13） |
| `https://www.bing.com/search?q=…` | 会 **302 到 `cn.bing.com`**（实测），等价 | 已实测（2026-10-13） |
| 站内限定 | 查询里写 `site:<域名> <词>` | 已实测（2026-10-13，`site:lswh.hubu.edu.cn 乐庆玲` 有效） |

- 免登录即可用，本轮全程**未触发验证码 / 人机验证**。
- 搜索结果页的 DOM 结构（抓取用）：
  - 结果条目：`#b_results > li.b_algo`
  - 标题 + 链接：`li.b_algo h2 a`（`innerText` / `href`）
  - 摘要：`li.b_algo .b_caption p`（部分条目为 `.b_lineclamp2` / `.b_algoSlug`）
- 一段可直接用的取数片段（browser_evaluate）：

```js
() => {
  const out = [];
  document.querySelectorAll('#b_results > li.b_algo').forEach(li => {
    const a = li.querySelector('h2 a');
    const p = li.querySelector('.b_caption p, .b_lineclamp2, .b_algoSlug');
    out.push({ t: a ? a.innerText : '', u: a ? a.href : '', s: p ? p.innerText.slice(0,300) : '' });
  });
  return JSON.stringify(out, null, 1);
}
```

## 检索要点

- **定位优先于取证**：本站在本模式里只用来①确认"这篇文献在哪个库"②拿 DOI / 题录线索
  ③确认"这个人物该去哪个官方站看"。**任何要写进答案的事实，必须再点进原站核对。**
- **零结果判定**：页面上出现 `没有与此相关的结果: "<查询>"` 且 `#b_results` 内**没有** `li.b_algo`
  —— 这就是"确无收录"，不是加载没完（实测：等 2~3 秒后仍是该状态）。
  一句话判定：`document.body.innerText.includes('没有与此相关的结果')`。
- **人物站内检索很有效**：`<人名> <单位>` 一次就给到百科、单位官网、导师介绍、出版社作者简介四类源
  ——这四类刚好能互相补：官网/单位简介定性，百科给出生年份。

## 坑与对策

| 坑 | 对策 |
|---|---|
| ⚠️ **给中文"长题名"加英文双引号做精确匹配 ⇒ 直接零结果**（**不是"加引号必零"**，2026-10-13 已更正口径） | 已实测：`"媒体深度融合背景下高校数字图书馆用户持续使用意愿影响因素研究"` → 「没有与此相关的结果」。但**同一轮实测**：`"臭乐乐" 猫 表情包 意思`（引号内仅 3 字）**正常命中 10 条** ⇒ 触发条件是**引号内是长句/整条题名**，短词加引号做精确匹配是**可用**的。**对策：长题名去掉引号再搜**；确定是学术文献就直接转数据库（万方 `paper?q=` 深链命中 1 条） |
| ⚠️ **学位论文（尤其近 2 年、非顶校）在通用搜索引擎里基本不被收录** | 已实测同一天：同一篇 2025 年硕士论文，加引号、不加引号、加作者名，Bing 三次全部零结果；而在万方**一次命中**。⇒ **学术文献类题目不要耗在搜索引擎上**，搜索引擎只用来定"去哪"，一旦知道就直接下数据库 |
| ⚠️ 搜索摘要 ≠ 证据 | 摘要可能来自其它相似文献（实测：搜本论文题名时，返回的全是**主题相近但不同**的其它论文）。**写进答案前必须打开原站页面看到该字段** |
| ⚠️ 截图默认落点不是工作目录 | `browser_take_screenshot` 传相对路径 `./x.png` 时，实际落在 `$env:USERPROFILE\.dsh\profiles\desktop\`。**截图后要手动 `Copy-Item` 到工作目录**，否则用户复核时找不到文件 |
| ⚠️ 结果页滚动懒加载 | 只取 `#b_results > li.b_algo` 时首屏通常已有 10 条；需要更多时先滚动到底再取 |
| ⚠️ 触发验证码时 | **立即停手交回用户**（本模式第一原则），并把"哪个动作触发"写回本文件 |
