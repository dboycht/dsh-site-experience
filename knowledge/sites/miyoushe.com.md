## 检索要点

- **`文章发表：` 是本站最值钱的字段**：梗类内容时效性强，**用它给梗定年月**，
  且它常**早于** B 站切片/贴吧讨论 ⇒ 是"这个说法最早什么时候出现"的硬证据。
- **发帖版块=圈层定性**：实测该帖来自 `酒馆`（闲聊/吐槽版）⇒ 说明它是**情绪帖/吐槽帖**，不是攻略帖。
- **正文口语化，可整段抄**：玩家会用讽刺口吻直接写出梗的用法（实测原句见下），
  **是"这个称呼带不带恶意"最直接的语料**。
- **配合贴吧读**：米游社给"什么时候开始骂"，贴吧给"后来怎么骂" ⇒ 两站拼出时间线。

## 坑与对策

| 坑 | 对策 |
|---|---|
| ⚠️ **整页 `innerText` 里页脚占比很大**（协议/备案/客服电话/App 引导） | 用 `indexOf(标题关键词)` 切片取正文，别整页往回拉 |
| ⚠️ 帖子可能被删/被限流 | 抄证据时带 **文章 ID + 标题 + 发表日期 + 抓取日期** |
| ⚠️ **是玩家帖，不是官方帖** | 只用于"舆情/用法/时间"，**设定事实回游戏原文或 `mzh.moegirl.org.cn`** |
| ⚠️ 评论区多数为空（该帖 0 评论） | 站内互动量不是本站价值点，别拿"没人评论"当"这说法不流行" |
| ⚠️ 页面是 SPA，`document.title` 会晚于 DOM 就绪 | 导航后先 `browser_evaluate` 读一次 `document.title` 复核，再抄内容 |
| ⚠️ 截图默认落点不是工作目录 | 实际落在 `$env:USERPROFILE\.dsh\profiles\desktop\`，**必须手动 `Copy-Item` 到工作目录** |
| ⚠️ 触发验证码 / 要求登录时 | **立即停手交回用户**（本模式第一原则） |
