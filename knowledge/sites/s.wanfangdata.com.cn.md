## 检索要点

### 机构身份（已实测 2026-10-12）

- 页面右上角显示机构名（实测为「南京航空航天大学图书馆」）⇒ **持久 profile 已带机构身份**，
  机构订阅额度可用（结果页分面出现「机构已购」）。**不要**去登出或换 profile。
- 同时右上角仍有「登录 / 注册」按钮 ⇒ **未以个人账号登录**，只是机构身份被识别。
- 两轮全程**未触发验证码 / 滑块 / 登录墙**。

### 高级检索表单结构（已实测）

| 区域 | 内容 |
|---|---|
| 文献类型 | 10 个 chip：全部、期刊论文、学位论文、会议论文、**专利**、中外标准、科技成果、法律法规、科技报告、地方志。**专利题必须选中「专利」** |
| 检索信息 | 每行 = 字段下拉（宽 146px）+ 关键词框 + 匹配方式（模糊/精确）+ 逻辑运算符（与/或/非）+「+」加行；默认三行（主题/题名/摘要） |
| 日期 | 选中「专利」后为独立的**两行**：`申请日：` 与 `公开日：`，各含起止两个日期框（页面自带说明） |
| 智能检索 | 中英文扩展（默认**勾选**，结果页会显示「检索表达式（中英文扩展）」）/ 主题词扩展 |
| 操作 | 「检索」按钮、**检索历史** |

⚠️ **坑（已实测 2026-10-12）**：打开 `advanced-search/patent` 时表单**已经是专利表单**（字段=主题/题名/摘要，
日期=申请日/公开日）。此时若再去点「专利」chip，表单会被重置（字段变「请选择」、日期变「发表时间」、
字段下拉出「无匹配数据」）。**对策：进页面后不要再点「专利」chip，直接用默认专利表单**；已误点则重新导航该 URL 即可恢复。

### 简单检索（可深链，找人/找单篇最快，已实测 2026-10-12）

- 形如 `https://s.wanfangdata.com.cn/paper?q=<题名>` 或 `…/patent?q=<词1> <词2>`，**可直接深链、可分享、可复现**。
- 多词用**空格**分隔即跨字段召回（实测 `蒜薹采收机 苑进` → 命中 2 条同一件的 A/B 记录）。
- 结果页会显示「找到 N 条文献」＋左侧分面（获取范围 / 资源类型 / 年份 / 作者 / 机构）。
- **论文题录按作者顺序列出**（实测 `苑进 陶凯 辛振波 等`）⇒ 取「第一作者」直接读第一个。

### 专利详情页（已实测 2026-10-12）

| 区块 | 内容 |
|---|---|
| 主体 | 标题、摘要、`专利类型`、`申请/专利号`、`申请日期`、`公开/公告号`（含 `关联公开/公告号`）、`公开/公告日`、主分类号、分类号、`申请/专利权人`、**`发明/设计人`（按顺序）**、申请人地址、代理机构、代理人、国别省市代码、`主权项`（权利要求 1） |
| 右侧栏 1 | **`专利图片`**：swiper 轮播，幻灯片标注 `N / 总数`；**内容 = 该专利的说明书附图** |
| 右侧栏 2 | `法律状态`：时间线表格（日期 + 状态，如 `2025-10-10 授权`），可点「详情」 |
| 右侧栏 3 | `相关文献`、`相关学者`、`相关机构` |
| 操作 | `在线阅读`（**付费**，实测弹到 my.wanfangdata.com.cn/user/transaction，单价 3 元 → **不要付款，改用外部全文源**）、`下载`、`引用`、`收藏` |

- **专利图片直链规律**（可用于批量抓图，无需登录）：
  `https://f.wanfangdata.com.cn/api/resource/pc/patentimg/<公开号如CN2025118160500B>%2F<HDA...>.GIF`
  —— 文件名尾号形如 `11 / 12 / 21 / 22 / 31`（疑似「页码+图序」），**总数以轮播 `N / 总数` 为准**。
- 实测 CN118160500B：轮播 5 张，与官方说明书 `附图说明` 的 图1–图5 完全对应。

### 字段清单（专利高级检索下拉，**全部 15 项，已实测 2026-10-12**）

```
全部、主题、题名、摘要、专利-发明/设计人、专利-申请/专利号、专利-申请/专利权人、
专利-公开/公告号、专利-主权项、专利-优先权、专利-主分类号、专利-分类号、专利-代理人、专利-代理机构
```

- ⚠️ **字段下拉里没有「法律状态」，也没有「专利类型」** ⇒ 这两个条件**只能在结果页分面里加**。
- 权利人字段写作 **`专利-申请/专利权人`**（页面表格内有时渲染为「专利—申请/专利权人」）。
- **「主题」字段 = 题名 + 关键词 + 摘要**（页面自带说明，已实测）。
- **「题名或关键词」**不在专利下拉里（该说明属论文侧），专利侧用「题名」。

### 日期字段（已实测 2026-10-12）

- 专利侧日期有两行：**申请日** 与 **公开日**，各自「起 — 止」。
- 日期框是 iView DatePicker，`<input readonly>`，**不能直接输入**，必须点开面板：
  点年份标签 → 选年 → 点月份标签 → 选月 → 点日。面板左侧有快捷项：
  - 起始框（占位「不限」）：一周前 / 一月前 / 半年前 / 一年前 / **今年初** / 三年前 / 十年前
  - 结束框（占位「至今」）：一周前 / 一月前 / 半年前 / 一年前 / **去年末** / 三年前 / 十年前
- 选完后面板自动关闭，输入框显示 `2021-01-01` 这类文本。
- 结果页显示的表达式形如 `申请日:[2021-01-01 TO 2025-12-31}`（左闭右开括号渲染；2026-10-10 曾渲染为 `{…}`，含义未见差异，**待确认**）。

### 结果页结构（已实测 2026-10-12）

- 计数文本：结果区标题 **「找到 N 条文献」**（在检索表达式下方）。
- 检索表达式会整条回显在结果页（含「检索表达式（中英文扩展）」一行）。
- 左侧分面（`.wf-facet-box`）依次为：
  **获取范围**（机构已购 / 境内专利 / 有全文 / 境外专利）、**IPC分类**、**专利类型**、
  **国家/地区/组织**、**公开/公告年份**、**法律状态**、**有效性**、**申请/专利权人**、**发明/设计人**。
  - 折叠的分面（国家/地区/组织、法律状态、有效性…）需**点击标题展开**，数值是异步加载的，展开后要等 1~3 秒。
  - **分面数字是"当前已选项内"的计数**：加了「发明专利」后，专利类型分面就只剩发明专利，其它选项消失。
- **分面勾选后必须点面板底部「确定」才生效**；生效后标签区出现 `专利类型 : 发明专利`（带 × 可单删），
  面板内「清空」只清当前勾选、不影响已生效条件。
- 结果项 = `.normal-list`，单条文本结构：

```
1.<标题>发明授权            ← 第 1 行：序号.标题 + 文献标签（发明授权 / 发明公开）
[专利]发明专利CN117610641B中国人民解放军国防科技大学申请日：2023-12-08   公开日：2026-08-04
摘要：…
在线阅读 下载 引用 收藏
```

- **标题不是 `<a href>`**，点击由 JS 打开新标签页的详情页。
- 翻页：底部 `.bottom-pagination`，含 `.prev`（上一页）、`.next`（下一页）、`.pager`（页码）。
  - `.pager` **只渲染当前页附近的约 7 个页码**＋当前页（做导航时别指望直接点到第 1 页；用 `.prev` 回退）。
  - 每页固定 20 条（页面显示「显示 20 条」，其它页长**待确认**）。

### A/B 双记录（**关键语义，已实测 2026-10-12**）

- 同一个申请在结果集里会出现**两条**：`…A`（发明公开）与 `…B`（发明授权），标题相同、申请日相同、公开号尾字母不同。
- 详情页直接写明关联关系：`公开/公告号：CN119418148A（关联公开/公告号：CN119418148B）`。
- **「法律状态 = 授权」会把同一件的 A、B 两条都返回**（详情页右侧「法律状态」时间线显示
  `2025-10-10 授权 / 2025-02-28 实质审查的生效 / 2025-02-11 公开`）。
- ⇒ 平台「条数」是**文献记录数**，约等于 **2 × 件数**。题目若问「多少项」，按平台条数作答（选项通常按条数设计）。

### 论文 / 学位论文检索（**已实测 2026-10-13**）

- ⚠️ 本手册此前**只覆盖了专利侧**。而题目里有大量**论文题**（作者 / 导师 / 引用 / 被引）——
  它们**不会**在题面里写"在万方中"，所以**不要**因此就退回通用搜索引擎：**论文侧也在本平台**。
- ⭐⭐ **一句话结论：学位论文详情页有「导师姓名」字段** —— 「论文题名 → 作者 + 硕士导师」这一跳
  **可以在万方一步完成，不用猜、不用去知网**。

#### 走法（可复现，三步）

1. **深链简单检索**（用**完整题名**，不加任何符号）：
   `https://s.wanfangdata.com.cn/paper?q=<完整题名>`
   实测命中「找到1条文献」（2026-10-13，题名：《媒体深度融合背景下高校数字图书馆用户持续使用意愿影响因素研究》）。
   （**待确认**：题名加引号 `"…"` 是否仍等价 —— 本轮未在万方侧测引号；只在 Bing 侧测出"加引号=零结果"，见 `cn.bing.com.md`。）
2. **从结果条目取隐藏 ID**：结果条目的 HTML 里有
   `<span class="title-id-hidden">thesis_D04474033</span>`（期刊侧形如 `perio_…`，**待确认**）。
   结果行文本形如：`[硕士论文]阮帅 图书情报 湖北大学 2025`。
3. **拼详情页 URL**：去掉 `thesis_` 前缀 →
   `https://d.wanfangdata.com.cn/thesis/D04474033`
   ⇒ 标题在列表里**不是 `<a href>`**（点击由 JS 开新标签），所以上面这条"抄 ID 拼 URL"是**唯一可复现路径**。

### 说明书附图（⚠️ **待确认** —— 2026-10-12 尚未验证）

## 坑与对策

| 坑 | 对策 |
|---|---|
| ⚠️ **点页码后读到上一页内容（stale DOM）** | **已实测踩到**：抓第 2 页时拿到第 1 页的 20 条（公开号与第 1 页完全重复）。**对策**：点击后轮询直到「`.page-number` = 目标页」且「首条序号 = (p−1)×20+1」且「首条公开号 ≠ 上一页首条」，最多等 ~15 秒再取数 |
| ⚠️ 进页面就点「专利」chip 会把表单重置成空 | 直接用默认专利表单，别点 chip；误点就重新导航 `advanced-search/patent` |
| ⚠️ 字段下拉里没有「法律状态」「专利类型」 | 这两个条件只能在**结果页分面**加，且必须点**确定** |
| ⚠️ 分面数字是"当前已选项内"的计数，加了筛选后其它选项会消失 | 想做减法口径核对（如"授权全集 − 实用新型授权"）就先只留一个筛选，读分面，再加另一个 |
| ⚠️ 日期框 readonly，直接 type 无效 | 点开面板按"年→月→日"选；或先设一个已知日期再改 |
| ⚠️ 计数**随时间变化** | 实测：同一检索式 2026-10-10 = 326 条，2026-10-12 = 332 条（+6 = +3 件 A/B 对）。落答案时**必须记下检索日期**，并在选项里选最接近的 |
| ⚠️ 结果页无深链参数 | 复现只能重走表单＋分面；把用过的表单值、生成的表达式**抄下来写回本文件** |
| ⚠️ 未触发过验证码 | 触发时**立即停手交给用户**（本模式第一原则），并把"哪个动作触发"写回本文件 |
| ⚠️ 专利详情的 `在线阅读` 是**付费**的 | 实测点开后跳到 `/user/transaction`（3 元/篇）。**不要付款**；要说明书全文（含「附图说明」）改用 `patentscope2.wipo.int`，要附图纸用详情页右侧「专利图片」面板 |
| ⚠️ 需要「说明书附图个数」这类全文细节时平台只给图不给文 | 详情页只看得到摘要/主权项，**说明书正文不在万方免费范围**；用「专利图片」数图 + 外部官方全文交叉确认 |
| 需要个人登录才有完整功能 | **交回用户**登录一次（持久 profile 会记住），不要自行尝试 |
