```js
() => {
  const h = [...document.querySelectorAll('h3')].find(e => e.innerText.includes('<梗名>'));
  if (!h) return 'not found';
  let out = [h.innerText];
  for (let n = h.nextElementSibling; n && n.tagName !== 'H3'; n = n.nextElementSibling) out.push(n.innerText);
  return out.join('\n');
}
```

- 只想确认"这词在不在这页"时，直接全文检索 `document.body.innerText.indexOf('<梗名>')` 更快。

## 检索要点

- **词条名 = 人物/作品名，不是梗名**：梗（如「飞八分钱」）是**挂在人物词条下的一个三级标题**，
  ⇒ 正确路径是「搜梗名 → 拿到人物 → 打开人物词条 → 在页内找该梗的小节」，**别指望有梗的同名词条**。
- **目录就是梗的清单**：左侧导航列出全部 `2.x` 小节，一眼能看出这个词条收了哪些梗；
  要批量判断"某主播有哪些知名梗"，读目录比读正文快。
- **正文段落逐字可抄**：梗的出处常写成一段完整叙述（含弹幕原文、缩写、衍生梗），
  是**可以整段当证据**的形态 —— 比搜索引擎摘要可靠得多。
- 交叉源优先级：① 百度贴吧原帖（社区会互相纠错，**误传词源常在回帖里被否掉**）；
  ② 知乎问题页高赞回答（看"当前怎么用"）；③ `cnmeme.wiki`（看简短释义与攻击性定性）。

## 坑与对策

| 坑 | 对策 |
|---|---|
| ⚠️ **梗没有独立词条，按梗名搜站内会扑空** | 先搜人物名再页内定位；见「检索要点」第 1 条 |
| ⚠️ **网络用语本身也常无独立词条（404）** | 实测 `乐子` → 404、`乐子人` → 命中 ⇒ **加后缀试**（`人`/`梗`/`猫`/`文化`）；仍 404 就别耗，转 `cnmeme.wiki` |
| ⚠️ 词条里的出生年 / 身份等**不是本题需要的**，但会污染上下文 | 只取目标 `h3` 及其后续同级段落，别整页 `innerText` 拉回来（实测整页 4875 字符里大部分是分类导航表） |
| ⚠️ 编辑型 wiki，词源可能被人改 | 抄证据时**连"最后编辑于"日期一起抄**；并至少再找一个独立源（贴吧/知乎） |
| ⚠️ 截图默认落点不是工作目录 | `browser_take_screenshot` 传相对路径时实际落在 `$env:USERPROFILE\.dsh\profiles\desktop\`。**必须手动 `Copy-Item` 到工作目录**（对外路径直接写工作目录会被拒：`outside allowed roots`） |
| ⚠️ **首跳可能 `net::ERR_TIMED_OUT`（实测 1 次）** | 直接**原 URL 重试一次**即成功（第二次正常加载）⇒ 别一次超时就判定"站点不可用"或转别的源 |
| ⚠️ **电竞选手/现实人物也有词条，但最新梗往往还没写进去** | 实测《无畏契约》选手「郑永康」词条在（页面最后编辑 2026-05-19），信息栏有 `别号`（含「康神」）、`生日`、`所属战队`、`职业ID`，正文有赛事史；但**全文不含**「抗渗」「kskbl」「开播」⇒ **萌百能给你"这个人是谁/别号有哪些"，给不了"最近三个月才爆的梗"**；此时词源要去 `tieba.baidu.com` |
| ⚠️ 触发验证码时 | **立即停手交回用户**（本模式第一原则），并把"哪个动作触发"写回本文件 |
