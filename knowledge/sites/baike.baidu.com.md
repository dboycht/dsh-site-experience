## 检索要点

- **首段就是结论**：词条第一段通常写成
  `XXX，女，1979年生，<籍贯>人，<职称>，<毕业院校>博士毕业。现任…`
  ⇒ 出生年份**在首段明文**，不必翻信息栏。
- **信息栏（右侧/正文上方的键值表）** 才是结构化取值点，键名实测有：
  `中文名`、`国籍`、`出生地`、**`出生日期`**、`学位/学历`、`职业`、`专业方向`、`性别`、`毕业院校`、`学术代表作`。
  取值片段（browser_evaluate）：

```js
() => {
  const els = [...document.querySelectorAll('dt, dd')];
  const target = els.find(e => e.innerText.trim() === '出生日期');
  if (!target) return 'not found';
  target.scrollIntoView({ block: 'center' });
  return '值=' + (target.nextElementSibling ? target.nextElementSibling.innerText.trim() : '?');
}
```

- 本轮实测返回 `值=1979年`，与首段「1979年生」一致（**同页双视角互证**）。

### 网络流行梗类词条（已实测 2026-10-13）

- 新梗常有**独立词条**，且正文有固定小节：**`词语释义` / `词语来源` / `应用` / `影响` / `相关衍生`**，
  末尾带 `词条统计`（浏览次数、编辑次数、**最近更新**）与 `参考资料`（常只有 1 条二手来源）。
- 取正文最省事的写法（绕开导航）：

```js
() => { const t = document.body.innerText; const i = t.indexOf('词语来源'); return t.slice(i > 0 ? i : 0, (i > 0 ? i : 0) + 2500); }
```

- 实测 `baike.baidu.com/item/kskbl/69122469`、`…/item/康神开播了/69135277` 两个词条：
  `词语来源` 段落是**可直接整段当证据**的叙述体（含时间、人物、事件）。
- ⚠️ 这类词条**更新时间极新、编辑次数仅 2 次、参考资料只有 1 条**（实测两个词条都引「游侠网」）
  ⇒ **属于"词条即二手转述"**，只能当"该说法已进入公共词条"的证据，事实本身要另找一手源。
- ⚠️ 梗类词条会把**同义/谐音变体各开一个词条**（实测 `kskbl` 与 `康神开播了` 是两条）；
  想覆盖某梗的**黑称/变体**，得**按变体名再搜一次**，主词条未必写。

### 网络流行语类词条（已实测 2026-10-13）

- **另有"流行语"型词条**（实测 `搞快点/65185180`），结构与梗类不同：
  正文小节为 **`定义` / `起源与发展` / `用法与语义`**，且**信息栏是一张可直接抄的结构化结论表**：
  `中文名`、`含 义`、`外文缩写`、`起源时间`、`常见场景`、`起源平台`、`传播范围`。
- ⇒ 这类词条**信息栏 + `定义` 段**两处就够写答案；但正文里有大量**相关星图/词条推荐**（实测首页混进
  "APP""ACG""ACGN""白嫖"等 160 个词的推荐卡）⇒ **别整页 `innerText`**，按小节切片。
- ⚠️ **正文会把人名写混**：实测原文写「主播**李赣（孙笑川）**」，而李赣与孙笑川是 6324 的**两个人**
  ⇒ **百科给的时间线可用，人物关系必须另找源核对**（该例靠 `zhihu.com` 的问答核对）。
- ⚠️ 参考资料常是**聚合站/内容站**（单词乎、游侠网、中华网…）⇒ 仍是二手转述，**须交叉源**。

### 事件类词条（已实测 2026-10-13，⭐ 舆情/事故题的"时间线聚合"最佳入口）

- **重大社会/产业事件会开出独立词条**，且结构固定为：
  **`事件背景` / `事件经过` / `事件回应` / `相关法规` / `事件争议` / `事件影响` / `社会评论`**，
  开头另有一句**摘要式导语**（把日期、机构、核心动作、结论压成一段）。
- ⚡ **`事件回应` 一节是表格**，按**回应方**（企业 / 母公司 / 品牌方 / 当事测评机构 / 大 V）分行列出**原话**，
  并带参考编号 ⇒ **一次就能把"各方分别怎么说的"拿全**，比逐个搜新闻快得多。
- ⚡ **`事件争议` 一节会把反对意见具名化**（实测：某制动系统公司董事长认为属"滥用工况"、某学会分会副秘书长认为"日常急刹不能触发断裂"、
  测评方负责人连发微博质疑"静态加载和动态加载一样么"）⇒ 这是**回答"争议在哪"最省事的一段**。
- ⚡ **`相关法规` 一节给标准号与关键数字**，且**末尾 `参考资料` 会标出每条来自哪家媒体** ⇒ 可顺着参考编号去原站核（本轮据此核到 `yicai.com`）。
- ⚠️ **但导语/正文可能把"某一方的说法"写成客观陈述**：实测导语写「根据机动车制动踏板相关**强制标准**要求，制动踏板应能承受 **2000 牛**的作用力并保持 5 秒不失效」，
  而正文 `相关法规` 一节自己澄清「**强制性国家标准…不考核极端超大力踩踏的极限破坏**」、2000N 实际出自**赛事规则**、1500N 出自**推荐性行标** ⇒
  **同页内自相矛盾，必须逐节对读，并以"法规节+原站"为准**。
- ⚠️ `词条统计`（浏览次数 / **编辑次数** / 最近更新）要看：实测该事件词条 **编辑 34 次、最近更新"今天"** ⇒
  **正在发酵中的词条，数字随时会变，抄证据必须带抓取时刻。**

## 坑与对策

| 坑 | 对策 |
|---|---|
| ⚠️ **信息栏在长页面下方，直接截图看不到出生日期** | 截图前先 `element.scrollIntoView({block:'center'})`（见上片段），再 `browser_take_screenshot`；否则留证图里没有关键字段，等于没证据 |
| ⚠️ **百科是用户可编辑/LLM 摘要型内容，单独用不足以定案** | 必须**至少第二个来源**：① 另一部百科（实测用**快懂百科** `https://www.baike.com/wikiid/<id>`，同报 1979，且信息栏明列「出生日期 1979年」）；② 单位官网 / 出版的作者简介（可确认同人身份与职称，一般不含出生年） |
| ⚠️ 同名人物 | 用**单位 + 研究方向 + 毕业院校**三联核对（实测：湖北大学 + 信息资源管理/企业档案管理 + 武汉大学信息资源研究中心 = 同一人） |
| ⚠️ 词条里的职称可能过期 | 实测该词条首段仍写「讲师」，而湖北省社科专家库、武汉大学出版社作者简介均写「副教授」⇒ **职称不要从百科取**，取单位最新来源 |
| ⚠️ 触发验证码时 | **立即停手交回用户**（本模式第一原则） |
