## 检索要点

### 简单检索（最快）

1. 首页输入框 `#searchStr`，placeholder = 「请输入申请号、公布公告号或其他相关内容...」；
2. 可勾选类型（`#fmgb` 发明公布 / `#fmsq` 发明授权 / `#xxsq` 实用新型 / `#wgsq` 外观设计）；
3. 点 `button.sbtn`「查询」→ 跳 `/Dxb/IndexQuery`。

实测：输入 `CN118160500B` → 直接命中单件（无需勾类型）。

### 结果页结构（已实测）

- 工具条：`类型选择`、`公布模式`（**列表模式** / **附图模式**）、排序（`申请日` / `公布公告日`）、每页条数。
- 条目给出：类型标签（`[发明授权]` / `[发明公布]` …）、标题、授权公告号/公布号、对应日期、申请号、申请日、
  **同一申请的已公布的文献号**、专利权人、发明人、地址、分类号、摘要。
- 条目下方三个按钮：`发明专利` / `发明专利申请` / `事务数据`，均调用 `zl_xm('<key>','3','<日期>')`，**新开标签**到 `/Sw/SwDetail`。
- `附图模式` 调用 `change_showmodel('3')`：每个条目显示**公报扉页缩略图**（不是全部附图）。

### 公报扉页图的直链规律（已实测，可用于抓图）

```
http://epub.cnipa.gov.cn/imgs/ws2021/PUBXML/415202/FMSQ/FMSQ_DZGBD/<申请号>/100005/<申请号>_1.jpg
```
- 例：`…/2024105085279/100005/2024105085279_1.jpg`（约 245 KB）
- `…_1_thumb.jpg` 为缩略图；**该目录下只有第 1 页**（试 `_2_`…`_12_` 全为 404）。
- ⚠️ 直接请求**必须带 `Referer: http://epub.cnipa.gov.cn/Dxb/IndexQuery` 与浏览器 UA**，否则返回 **400**。

## 坑与对策

| 坑 | 对策 |
|---|---|
| ⚠️ **「下载PDF」弹算术题图片验证码** | **立即停手交回用户**（本模式第一原则），不要尝试识别。实测 2026-10-12 触发 |
| ⚠️ 该库只有**公报扉页**（含一幅代表图），**没有说明书全文/全部附图** | 数「说明书附图个数」要另找全文源：`patentscope2.wipo.int`（说明书含附图说明）或万方专利详情页「专利图片」面板 |
| ⚠️ 图片直链不带 Referer/UA 会 400 | 抓图时带上 Referer 与 UA |
| 目录无列举 | 只能按已知文件名规律取图；不要盲目遍历 |
| 事务数据页 `下载PDF`/`下载序列表` hover 才出现 | 按钮为 `javascript:openTips('<key>')`，点击即进验证流程 |
| 需要更强功能（全文检索/分析） | 那是「专利检索及分析系统」，需注册登录 → **交回用户** |
