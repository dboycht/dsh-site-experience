> 最后更新：2026-10-13 ｜ 状态：**已实测（问题页免登录可读标题/浏览量/部分回答全文）**
> ⚠️ 本文件只写**亲眼在页面上验证过**的东西。没验证的一律进「待确认」。
> 本文件是给 agent 看的作业手册，不是给人看的介绍。
>
> **定位**：本站在检索链里承担的是**「这个梗/概念现在怎么用、火到什么程度、有哪些衍生现象」这一跳**
> —— 它给的是**带时间线的用法叙述**（谁在用、怎么火的、后来怎么演变），
> 比百科"定义式"条目更接近真实语境。**词源仍以萌娘百科/贴吧为准。**

- 取正文（browser_evaluate）：

```js
() => {
  const t = document.body.innerText;
  const i = t.indexOf('<关键词>');
  return i >= 0 ? t.slice(Math.max(0, i - 300), i + 2500) : t.slice(0, 1500);
}
```

## 检索要点

- **页面自带三个可当证据的量化字段**（实测均在正文顶部明文）：
  `关注者`、`被浏览`、`N 个回答` ⇒ 用来佐证"这个梗的传播量级"，**比"据说很火"硬**。
- **答主身份会显示**（实测显示「华南理工大学设计学院信息与交互设计专业」等）⇒ 抄证据时带上答主名与赞同数。
- **看答主叙述里的时间词**：实测该回答把时间线讲得很完整（"两三年前"起源 → 斗鱼语音弹幕期，
  B 站有切片 → "沉寂一年后"靠 Suno AI 二次创作再火）⇒ **是回答"为什么现在突然有人问"的最佳素材**。
- **话题标签就是起源线索**：实测 `/question/301320638` 的标签是 `百度贴吧`/`流行词语`/`网络语言`/**`孙笑川`**/**`6324`**
  ⇒ **不用读正文也能看出这个梗挂在哪个圈层**，是定"该去哪个平台接着查"的最快一跳。
- **老问题的回答日期是"时间下限"证据**：实测该问题有 **2018-11-30** 的回答
  ⇒ 可用来支持"该说法**至少 2018 年就已在流传**"（比百科的"约2018年"更硬）。
- **同题多答案常互补**：实测高赞（572 赞同）给**宏观起源链**（斗鱼 6324 → 抗压吧 → 微博/抖音），
  次赞（65 赞同）给**具体桥段与原始引语**，第三答（40 赞同）给**使用语境**（哪些吧、催什么）
  ⇒ **三条拼起来正好是一份完整词源**，别只看最高赞。
- 回答末尾常带**站方插入的活动/推广段落**（实测有一段 LPL 投票推广）⇒ 摘录时要切掉，别当回答内容抄。

## 坑与对策

| 坑 | 对策 |
|---|---|
| ⚠️ **登录浮层容易误判为登录墙** | 实测 `document.body.innerText` 已含回答全文（整页 2228 字符）⇒ 先取文本再判断，别一看到弹窗就交回用户 |
| ⚠️ 只展示部分回答（实测 5 个回答中直出 3 个，其余折叠为"查看剩余 2 条回答"） | 需要更多时再点展开；**不要把"折叠"当成"没有"** |
| ⚠️ 站方推广段落混在回答尾部 | 摘录时以"答主署名 + 赞同数"为边界切分 |
| ⚠️ **这个站不一定收"骂人黑话"型梗** | 实测同一名选手：知乎只有理性讨论帖（评价空枪表现），**没有**「叛国/汉奸」这类攻击性黑话（检索全 -1）⇒ **查黑称/黑话别在知乎耗**，去 `tieba.baidu.com` 的对应"抗压吧"；知乎的"没有"可当**时间下限**用（说明该说法还没进入理性讨论区） |
| ⚠️ 答主是个人，词源可能是转述 | 词源交叉 `mzh.moegirl.org.cn` / `tieba.baidu.com`；本站只用于**用法与传播时间线** |
| ⚠️ 截图默认落点不是工作目录 | 实际落在 `$env:USERPROFILE\.dsh\profiles\desktop\`，**必须手动 `Copy-Item` 到工作目录** |
| ⚠️ 触发验证码时 | **立即停手交回用户**（本模式第一原则） |
